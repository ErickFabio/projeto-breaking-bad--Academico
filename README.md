# 🎬 Projeto Breaking Bad - Site Responsivo

Projeto acadêmico desenvolvido para a **Unidade IV - Designer Web**, com foco em responsividade mobile-first e estrutura semântica HTML5/CSS3.

## 📋 Sobre o Projeto

Site responsivo temático da série **Breaking Bad**, desenvolvido como trabalho acadêmico para demonstrar conhecimentos em:

- HTML5 semântico
- CSS3 com media queries
- Responsividade mobile/tablet/desktop
- Menu hambúrguer (CSS puro + JavaScript)
- Layout flexbox e grid
- Imagens de fundo responsivas

## 🚀 Como Visualizar

1. Clone este repositório:
```bash
git clone https://github.com/SEU_USUARIO/projeto-breaking-bad.git
```

2. Abra o arquivo `index.html` em qualquer navegador moderno.

## 📱 Responsividade

O site é totalmente responsivo com 3 breakpoints:

| Dispositivo | Largura | Comportamento |
|-------------|---------|---------------|
| Desktop | > 1024px | Menu horizontal à direita, layout completo |
| Tablet | 800px - 1024px | Menu hambúrguer, imagens em scroll |
| Mobile | Até 799px | Menu hambúrguer em tela cheia, elementos empilhados |

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização, variáveis CSS, media queries, flexbox
- **JavaScript** - Controle do menu hambúrguer e scroll
- **Google Fonts** - Montserrat e Open Sans
